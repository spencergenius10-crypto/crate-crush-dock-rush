## (1) Five repeatable post formats

### T1 — Smash ASMR
- **Hook (0–1.5s):** Extreme close-up of crate impact / wood splinter / metal latch snap. No UI chrome.
- **Body:** 4–8 rhythmic smash/clear beats. One crate family per cut (same size → satisfying cadence).
- **End:** Full dock clear or perfect stack settle. Cut on the last thud.
- **Repeatability:** Same framing, swap crate skins / dock skins / night vs day.

### T2 — Near-miss catch
- **Hook:** Crate mid-air, fingers / claw / dock edge in frame — freeze the almost-drop.
- **Body:** Catch at last frame → tiny settle bounce. Optional 1-beat replay of the miss threat.
- **End:** “.5s from disaster” text or none — audio does the work.
- **Repeatability:** Change height, wind, conveyor speed; always sell the almost-fail.

### T3 — Streak bait
- **Hook:** Big streak number on-screen (or shout it in first frame text): `12` / `27` / `50`.
- **Body:** Rapid clears while counter ticks. One near-break mid-clip (heart-rate spike).
- **End:** Freeze on new PB or cliffhanger before break. Pin comment: “can you beat X?”
- **Repeatability:** Daily PB posts; weekly “streak funeral” when it dies.

### T4 — Fail → retry
- **Hook:** Hard fail in first 1s (crate crush wrong bay / spill / overload).
- **Body:** Hard cut → retry with cleaner inputs. Same angle both takes.
- **End:** Clean clear. Caption admits the L then the fix.
- **Repeatability:** Same fail type series (overload, mistime, greedy stack).

### T5 — Comment “beat my X”
- **Hook:** Final score / time / crates cleared slammed on frame 1: `beat my 48`.
- **Body:** The run that earned it — tight, no tutorial talk.
- **End:** Hold score card 1s. First comment (brand): `beat my 48 — drop yours`.
- **Repeatability:** Swap metric (time attack, no-miss run, perfect dock).

## (2) Caption / sound notes

**Caption skeleton (all formats):**
```
[punch ≤8 words]

[optional via @creator if stitch]

#CrateCrush #DockRush #MobileGaming #ASMR
```
- Blank line after punch. 3–5 `#CamelCase`, space-separated.
- **Before Post:** tags must be blue/tappable (use suggestion chips). Never glue tags.
- Punch bank: `one more crate.` / `almost dropped it.` / `streak is illegal.` / `fail. then clear.` / `beat my 48.`

Prefer **native game SFX mixed under** a quiet trending bed when possible — smash readability first.

## (3) What NOT to film

- Long tutorial / feature tour / store UI walkthrough
- Soft-launch “wishlist now” hard sell as hook (soft CTA only after hook holds)
- Cluttered HUD covering the smash (mute-first rule dies)
- Paywall / IAP screens as content
- Fake staged “influencer hands” that hide the physics
- Random unrelated trends with no crate/dock payoff
- Dark unreadable night docks without rim light on the crate edge
- Multi-minute sessions — keep cuts 7–18s for algo
